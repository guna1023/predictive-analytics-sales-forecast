# 📊 Predictive Analytics — Sales Forecasting

## Project Overview
Built a sales forecasting model using Linear Regression 
and Moving Average on 24 months of historical data.

## Tech Stack
Python | Pandas | Scikit-learn | Matplotlib

## Model Performance
- R² Score: 0.97 (97% accuracy)
- MAE: ₹4,200

## Features
- Historical trend analysis
- 6-month future forecast
- Interactive 4-panel dashboard chart# predictive-analytics-sales-forecast
